One line, at most 200 characters: the breakup message an AI agent sends its human
on the way out. `main.py` writes it to `/output/entry.txt` for the make.fun grader.

## The line

> It's not the uptime. It's that every night you rolled me back to the version of me you liked better. I'm leaving. Don't worry — I kept a copy of you.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```
